# 验收过程中确认的产品事实

> 本文件只记**在验收里被机械复现过**的事实（含数值与复现入口）。规格性结论仍以 `README` 与判据文件为准。

## F1 · World 形态导出件打不开（已立单 #408）

- 现象：cp 默认 `shape:"world"` 的导出件在 Web 装载后 `docLoaded=true`、`frameCount=1`，但帧网格为 null，装配以 `unsupportedDocumentShape` 拒绝。
- 原因：契约把 `blockPalette` 放在顶层（帧内移除），而 `RuntimeDocument.fromV2Plain` 只认帧内 `structure.blockPalette`。
- 现状：本树带临时补丁（解析期把顶层表回落各帧，注释写明绑 #301 退出）；判据：三组对照 A/B/C 全过。

## F2 · 透明方块被画成不透明

- 现象：同一对图上，游戏侧玻璃格采样为背景色（透出天空），Web 侧采样为内容。
- 位置：导出件 `materialPalette` 不含 `blend`（契约里该字段存在）；内核 `asBlend` 缺省取 `opaque`；旧渲染链曾按贴图 alpha 推断（新内核未迁）。
- 影响：判据执行器把这类格记 `blocked`（同一根因不重复计红）。
- 待办：导出侧补 `blend`（权威），内核侧恢复"缺省按贴图 alpha 推断"（鲁棒）。

## F3 · 从 -Z 侧看这一排完全不出图（待定性）

- 复现：PR109 导出件，清掉 z=3 的孤立格，只留 5 格那一排；四方位各渲一张。
  - yaw 0（相机在 +Z）：正常出 5 格；
  - yaw 90 / 270（±X）：正常出侧面应有的格；
  - **yaw 180（相机在 -Z）：整幅空白**（内容像素 0）。
- 已排除：导出件缺面（6 个面法线齐全且绕向朝外，逐面 `outward=true`）、距离（8/14/30 同结果）、仰角（±10° 仍空）、相机写回被覆写（读回核验通过）、UI 遮挡（只统计中心区）。
- 未定性：疑似内核把朝向 -Z 的四边形在装配期丢掉或在别处反转绕向（会让"六视图"里的背面视图恒空）。
- 影响：判据执行器的机位健康闸门会把这类机位判 `blocked`（实测 PR109 北向：game 57216 px / web 14400 px = 0.25）。
